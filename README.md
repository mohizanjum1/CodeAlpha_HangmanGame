# CodeAlpha Hangman Game

A Python-based Hangman game built as part of the CodeAlpha Python Programming internship.

## Features
- 5 word categories: Technology, Science, Nature, Professions, Everyday
- 50 words total, each with 4 progressive hints (first hint free, others cost 1 wrong guess)
- ASCII art hangman drawing that updates with each wrong guess
- Colored console output (green for correct, red for wrong, yellow for warnings)
- Score tracking across multiple rounds
- Play again option after each round
- Supports both single-letter guesses and full-word guesses

## How to Run
1. Make sure Python 3 is installed
2. Run the file:
python hangman.py

3. Choose a category, then guess letters (or type 'hint' for a clue)

## Concepts Used
- Dictionaries and nested dictionaries
- Lists and string manipulation
- Functions
- Loops and conditionals
- ANSI escape codes for colored output
